# n8n-project

A personal playground for experimenting with **automation workflows using n8n**.  
This project is mainly for testing ideas, building small automations, and learning different workflow patterns.

## Tools

- **n8n** – workflow automation
- **Docker** – containerized environment
- **ngrok** – exposing local services for webhooks and external integrations

## Purpose

- Test automation ideas
- Experiment with integrations and APIs
- Build quick workflow prototypes
- Learn and explore n8n features

## Notes

This repository is not meant for production.  
It is purely a sandbox for automation experiments.
